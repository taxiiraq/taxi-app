# مجلد الأصول (Assets)

هذا المجلد يحتوي على جميع الأصول المستخدمة في التطبيق مثل الصور والأيقونات.

## الملفات المطلوبة

- `icon.png` - أيقونة التطبيق الرئيسية (1024x1024)
- `splash.png` - صورة شاشة البداية (1242x2436)
- `adaptive-icon.png` - أيقونة Android التكيفية (1024x1024)
- `favicon.png` - أيقونة الويب (48x48)
- `notification-icon.png` - أيقونة الإشعارات (96x96)

## ملاحظات

- تأكد من أن جميع الصور بتنسيق PNG
- احتفظ بنسخ احتياطية من الملفات الأصلية
- استخدم أداة ضغط الصور لتحسين الأداء
