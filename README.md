# تطبيق التاكسي للهاتف

تطبيق React Native شامل لإدارة خدمات التوصيل والتاكسي مع واجهات منفصلة للزبائن والسواق والمشرفين.

## المميزات

### 🚗 للزبائن
- تسجيل الدخول وإنشاء حساب
- طلب توصيل جديد
- تتبع حالة الطلب
- عرض الطلبات السابقة
- التواصل مع السائق
- دعم فني

### 🚘 للسواق
- تسجيل الدخول وإنشاء حساب
- عرض الطلبات الجديدة
- قبول الطلبات
- إدارة حالة التوصيل
- التواصل مع الزبون
- دعم فني

### 👨‍💼 للمشرفين
- لوحة تحكم شاملة
- إدارة الطلبات
- إدارة المستخدمين
- إدارة السواق
- نظام الدعم الفني

## التقنيات المستخدمة

- **React Native** - إطار العمل الأساسي
- **Expo** - منصة التطوير والنشر
- **TypeScript** - لكتابة الكود الآمن
- **React Navigation** - للتنقل بين الشاشات
- **React Native Paper** - لمكونات الواجهة
- **React Native Elements** - لمكونات إضافية
- **Supabase** - قاعدة البيانات السحابية
- **@supabase/supabase-js** - مكتبة Supabase
- **React Context** - إدارة حالة التطبيق

## التثبيت والتشغيل

### المتطلبات
- Node.js (الإصدار 16 أو أحدث)
- npm أو yarn
- Expo CLI
- حساب Supabase

### خطوات التثبيت

1. تثبيت التبعيات:
```bash
npm install
```

2. إعداد قاعدة البيانات:
- اتبع دليل `SUPABASE_SETUP.md`
- أنشئ مشروع Supabase
- نفذ ملف `supabase/schema.sql`
- أضف متغيرات البيئة في ملف `.env`

3. تشغيل التطبيق:
```bash
npm start
```

4. فتح التطبيق على الهاتف:
- تثبيت تطبيق Expo Go على الهاتف
- مسح رمز QR الذي يظهر في المتصفح

## الشاشات الرئيسية

### شاشات الزبون
1. **شاشة البداية** - شعار التطبيق وأزرار تسجيل الدخول وإنشاء الحساب
2. **شاشة تسجيل الدخول** - تسجيل الدخول بالبريد الإلكتروني وكلمة المرور
3. **شاشة إنشاء الحساب** - إنشاء حساب جديد مع اختيار الدور
4. **الشاشة الرئيسية للزبون** - عرض الطلبات السابقة وزر طلب جديد
5. **شاشة إنشاء طلب** - إدخال تفاصيل الطلب الجديد
6. **شاشة تتبع الطلب** - عرض حالة الطلب وبيانات السائق

### شاشات السائق
1. **الشاشة الرئيسية للسائق** - عرض الطلبات الجديدة وحالة الاتصال
2. **شاشة الطلب الحالي** - تفاصيل الطلب وأزرار التحكم

### شاشات المشرف
1. **لوحة التحكم** - تبويبات لإدارة الطلبات والمستخدمين والسواق والدعم الفني

### شاشة الدعم الفني
- واجهة لإرسال الرسائل والاستفسارات

## قاعدة البيانات (Supabase)

تم ربط التطبيق بـ Supabase كقاعدة بيانات سحابية. تتضمن:

### الجداول الرئيسية:
- **users** - بيانات المستخدمين (عملاء، سائقين، مديرين)
- **orders** - الطلبات والتوصيلات
- **support_messages** - رسائل الدعم الفني
- **notifications** - الإشعارات

### الميزات الأمنية:
- **Row Level Security (RLS)** - حماية البيانات
- **Authentication** - نظام مصادقة آمن
- **Real-time subscriptions** - تحديثات فورية

### الإشعارات التلقائية:
- إشعارات عند قبول الطلب
- إشعارات عند بدء التوصيل
- إشعارات عند إكمال التوصيل

### إعداد قاعدة البيانات:
راجع ملف `SUPABASE_SETUP.md` للحصول على تعليمات مفصلة حول:
- إنشاء مشروع Supabase
- تنفيذ schema.sql
- إعداد متغيرات البيئة
