# تطبيق التاكسي 🚗

تطبيق تكسي شامل مبني بـ React Native مع نظام خرائط مجاني وميزات متقدمة.

## ✨ الميزات

### 👥 للعملاء
- ✅ إنشاء طلبات تكسي
- ✅ تتبع السائق على الخريطة
- ✅ عرض معلومات الرحلة
- ✅ نظام دعم فني

### 🚘 للسائقين
- ✅ عرض الطلبات المتاحة
- ✅ خريطة تفاعلية مع موقع العميل
- ✅ تحديث حالة الطلب
- ✅ نظام تنبيهات

### 👨‍💼 للإدارة
- ✅ لوحة تحكم شاملة
- ✅ مراقبة جميع السائقين على الخريطة
- ✅ إدارة الطلبات
- ✅ تقارير وإحصائيات

## 🗺️ نظام الخرائط المجاني

يستخدم التطبيق **OpenStreetMap** كبديل مجاني لـ Google Maps:
- ✅ خرائط مجانية ومفتوحة المصدر
- ✅ دعم كامل للعراق والمنطقة العربية
- ✅ بحث عن العناوين
- ✅ حساب المسافات والاتجاهات
- ✅ معلومات الأحياء والمناطق

## 🛠️ التقنيات المستخدمة

- **React Native** - إطار العمل الأساسي
- **Expo** - منصة التطوير
- **Supabase** - قاعدة البيانات والمصادقة
- **React Navigation** - التنقل بين الشاشات
- **React Native Paper** - واجهة المستخدم
- **OpenStreetMap** - نظام الخرائط المجاني
- **Expo Location** - خدمات الموقع

## 📱 متطلبات النظام

- Android 6.0 (API level 23) أو أحدث
- iOS 12.0 أو أحدث
- اتصال بالإنترنت للخرائط والمصادقة

## 🚀 التثبيت والبناء

### 1. تثبيت التبعيات
```bash
npm install
```

### 2. بناء APK للأندرويد
```bash
# عبر GitHub Actions (موصى به)
# ارفع الكود إلى GitHub وسيتم البناء تلقائياً

# أو محلياً
cd android && ./gradlew assembleRelease
```

### 3. تشغيل التطبيق للتطوير
```bash
npm start
```

## 📁 هيكل المشروع

```
src/
├── components/          # المكونات القابلة لإعادة الاستخدام
│   └── FreeMapView.tsx # مكون الخريطة المجانية
├── contexts/           # سياق التطبيق
│   └── AuthContext.tsx # سياق المصادقة
├── lib/               # المكتبات
│   └── supabase.ts    # إعداد Supabase
├── screens/           # شاشات التطبيق
│   ├── admin/         # شاشات الإدارة
│   ├── customer/      # شاشات العملاء
│   └── driver/        # شاشات السائقين

│   ├── database.ts    # خدمات قاعدة البيانات

└── types/             # أنواع TypeScript
    └── index.ts       # التعريفات
```

## 🐛 حل المشاكل

### إذا كان التطبيق يخرج عند الفتح:
1. تأكد من وجود اتصال بالإنترنت
2. تحقق من إعدادات الموقع في الهاتف
3. أعد تشغيل التطبيق

### إذا فشل البناء:
1. تأكد من تثبيت جميع التبعيات
2. امسح cache: `npm start -- --reset-cache`
3. أعد تثبيت node_modules: `rm -rf node_modules && npm install`

### مشاكل التثبيت:
1. تأكد من تفعيل "مصادر غير معروفة" في إعدادات الأندرويد
2. تأكد من وجود مساحة كافية على الهاتف
3. أعد تشغيل الهاتف إذا لزم الأمر

## 📞 الدعم الفني

إذا واجهت أي مشاكل:
