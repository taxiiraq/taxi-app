# 🚗 تطبيق التاكسي - نظام خرائط مجاني

## 🆓 **نظام خرائط مجاني بالكامل**

تطبيق تكسي متكامل يستخدم **OpenStreetMap** بدلاً من Google Maps، مما يوفر:

- ✅ **مجاني 100%** - لا توجد رسوم
- ✅ **لا يحتاج مفتاح API** - سهل الإعداد
- ✅ **يعمل في العراق** - دعم كامل
- ✅ **جميع الميزات** - خرائط، بحث، اتجاهات

## 🚀 **الميزات المتاحة**

### **✅ للعميل:**
- 🗺️ **عرض الخريطة** - مجاني بالكامل
- 📍 **تتبع موقع السائق** - يعمل بدون تكلفة
- 🔍 **البحث عن العناوين** - دعم كامل للعربية
- 🏢 **الأماكن القريبة** - مطاعم، مدارس، حدائق
- 📱 **إنشاء طلبات** - سهولة في الطلب
- 📞 **اتصال بالسائق** - مباشرة من التطبيق

### **✅ للسائق:**
- 🚗 **عرض موقع العميل** - مجاني

- ⚡ **إدارة الطلبات** - قبول وإكمال

### **✅ للإدارة:**
- 👥 **مراقبة السائقين** - مجاني

## 🚀 **البدء السريع**

### **1. تثبيت المتطلبات:**
```bash
# تثبيت Node.js (الإصدار 18 أو أحدث)
# تثبيت Expo CLI
npm install -g @expo/cli
```

### **2. استنساخ المشروع:**
```bash
git clone https://github.com/your-username/taxi-app.git
cd taxi-app
```

### **3. تثبيت المكتبات:**
```bash
npm install
```

### **4. تشغيل التطبيق:**
```bash
npx expo start
```

### **5. بناء APK:**
```bash
cd android && ./gradlew assembleRelease
```

## 🎯 **المزايا**

### **✅ الأمان:**
- **مفتوح المصدر** - شفاف وآمن
- **لا تتبع** - لا تجمع بيانات شخصية
- **محلي** - يعمل بدون اتصال بالإنترنت للخرائط الأساسية

### **✅ الأداء:**
- **سريع** - تحميل فوري للخرائط
- **خفيف** - لا يستهلك موارد كثيرة
- **موثوق** - يعمل في جميع الظروف

### **✅ التكلفة:**
- **مجاني 100%** - لا توجد رسوم
- **لا حدود** - استخدم كما تريد
- **لا مفاتيح** - لا تحتاج إعداد معقد
